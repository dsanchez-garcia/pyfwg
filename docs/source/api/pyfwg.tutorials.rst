pyfwg.tutorials package
=======================

Notebook tutorials
------------------

Use :func:`pyfwg.utils.copy_tutorials` to copy the packaged notebooks and
example files into a working folder. The documentation uses the same notebook
sources. Regional EPWs and FWG JARs are supplied separately.

All eight notebooks include executed outputs and embedded plots. Compare the
full and direct alternatives in :doc:`../tutorial_comparison`.

* :doc:`CORDEX-CMIP5: all nine regions <../tutorials/cordex_regions_example>`
* :doc:`Direct morphing API <../tutorials/epw_morph_global_europe_example>`
* :doc:`Workflow classes <../tutorials/morphingworkflow_global_europe_example>`
* :doc:`Parametric iterator <../tutorials/morphingiterator_example>`
